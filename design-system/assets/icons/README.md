# Icons

Lucide (ISC licence) — https://lucide.dev · source https://github.com/lucide-icons/lucide

**Substitution flag:** the Amplio sources contain no icon set of their own. Lucide was chosen
as the closest match to the brand's character: single-weight 2px strokes with round caps and
joins, humanist proportions, and open forms — warm rather than mechanical, which is what the
brand brief asks for ("Organic > Geometric, Flowing > Angular"). If Amplio commissions a
bespoke icon set, replace this directory and the `Icon` component keeps working.

## Rules
- 24×24 viewBox, 2px stroke, never filled.
- Icon colour is always `currentColor` — the `Icon` component uses a CSS mask so icons inherit text colour.
- Sizes: 16 (inline/UI), 20 (buttons), 24 (default), 32/40 (feature marks).
- Never mix another icon family into the same view. Never use emoji as an icon.
