A client quote. Set in the display face at 20–28px, opened by a quote glyph.

```jsx
<Testimonial quote="I stopped dreading Monday mornings." name="Priya Raman" role="Life coach, Bristol" />
```

Keep quotes short and in the client's own words. Attribute by first name, surname and trade — never "CEO, Anonymous Corp". There is no avatar slot on purpose: the sources contain no client photography.
