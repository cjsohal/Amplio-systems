The brand logo — use this rather than an `<img>`, so only approved files and variants can be used.

```jsx
<Logo variant="lockup-light" height={32} href="/" />
```

The Atlas sub-brand has its own lockup: `atlas-colour` (+ `-light`, `-ink`). Use it only on Atlas surfaces, never as a substitute for the Amplio logo.

Pick `lockup-light` / `mark-cream` on dark or green backgrounds, `lockup-colour` on cream and white. Keep clear space equal to the cap height of the "A" on every side. Never add a shadow, outline or rotation.
