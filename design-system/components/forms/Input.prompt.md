Standard text field — 10px radius (fields are less round than buttons), green focus ring.

```jsx
<Input label="Work email" type="email" placeholder="you@practice.com" iconLeft="mail" required />
<Input label="Phone" error="Enter a number we can reach you on" />
```

Labels are sentence case and plain-spoken ("Work email", not "EMAIL ADDRESS *"). Placeholders show an example, never repeat the label.
